# 🍣 스시덴도감

**첫 알바, 레벨 1부터 시작하자!**

스시덴도감은 회전초밥집 스시덴고쿠에서 아르바이트를 처음 시작하는 사람을 위한 비공식 안내 사이트입니다. <br>
첫 출근 준비, 기본 업무, 손님 응대, 급여 확인, 실수 대처처럼 신입이 자주 마주치는 상황을 게임의 스테이지와 공략 형식으로 정리했습니다. <br> 
목원대학교 교양 수업 실습 프로젝트로 제작했습니다.

**[스시덴도감 사이트 열기](https://030-4aud.github.io/SushidenDogam/)**

## 제작 의도

첫 출근을 앞두면 무엇을 준비해야 하는지, 모르는 일이 생겼을 때 어떻게 질문해야 하는지 막막할 수 있습니다. <br>  
상황별로 정보를 나누고, 필요한 공략을 검색한 뒤 행동 요령과 체크리스트까지 확인할 수 있도록 구성했습니다. <br> 
우드 톤과 픽셀 글꼴, 스테이지 카드로 회전초밥집과 레트로 게임의 분위기를 표현했습니다.

## 주요 구현 기능

| 기능 | 동작 방식 |
| --- | --- |
| 공략·경험 글 검색 | 검색어를 URL의 `q` 값으로 받아 카드의 제목, 분류 태그, 요약을 검색합니다. 여러 단어를 입력하면 모든 단어가 포함된 카드만 표시합니다. 검색 결과 수 또는 결과가 없다는 안내를 표시하고, 전체 목록으로 돌아갈 수 있습니다. |
| 생존 팁 전환 | 홈에서 **다음 팁**을 누르면 미리 작성한 팁 5개를 순서대로 보여 줍니다. |
| 자동 목차 | 공략 본문의 소제목(`h2`)을 읽어 목차 링크를 만듭니다. 목차를 접고 펼치거나 원하는 항목으로 바로 이동할 수 있습니다. |
| 체크리스트 | 공략 상세의 확인 항목을 체크박스로 표시해 준비 여부를 직접 표시할 수 있습니다. 체크 상태는 현재 화면에서만 유지됩니다. |
| 반응형 화면 | 화면이 좁아지면 카드 배치와 열 수가 바뀝니다. 모바일에서는 **메뉴** 버튼으로 상단 내비게이션을 열고 닫을 수 있습니다. |

## 기술 구성

- **HTML**로 6개 페이지와 검색 폼, 공략·경험 글 카드를 구성했습니다.
- **CSS**는 [style.css](style.css)에서 공통 색상과 글꼴, 카드 레이아웃을 관리합니다. Grid와 미디어 쿼리로 화면 너비별 배치를 조정합니다.
- **JavaScript**는 [menu.js](menu.js)에서 검색, 모바일 메뉴, 팁 전환, 목차, 체크리스트를 처리합니다. 검색은 페이지에 포함된 카드 데이터를 브라우저에서 필터링합니다.
- **GitHub Pages**로 정적 사이트를 배포했습니다. 안내 캐릭터 이미지는 [assets](assets/)에 있습니다.

## 시연 순서

1. **홈**에서 **다음 팁**을 눌러 안내 문구가 바뀌는지 확인합니다.
2. **생존도감**에서 `급여`를 검색하면 **급여명세서 꼼꼼히 확인하기** 카드가 표시됩니다. **전체 공략 보기**로 목록을 복원합니다.
3. 목록에서 <b>첫 출근, 이것만 챙기면 준비 완료!</b>를 엽니다. 목차에서 **확인용 체크리스트**로 이동한 뒤 항목에 체크해 봅니다.
4. **경험 공유**의 검색창에 `주문`을 입력하면 **주문 확인할 때 도움이 된 말** 카드가 표시됩니다.
5. 브라우저 창을 모바일 크기로 줄인 뒤 **메뉴**를 눌러 페이지를 이동합니다.

## 현재 구현 범위

생존도감은 5개 스테이지를 소개하며 목록 검색을 지원합니다. <br> 
스테이지 카드는 공략 목록으로, 공략 카드는 첫 출근 공략 상세 예시 한 페이지로 연결됩니다. <br> 
경험 공유 화면은 예시 글 목록과 키워드 검색을 지원합니다. <br> 
경험 글의 개별 상세, 분류별 필터, 글 작성과 댓글, 로그인과 회원가입은 화면 시안 범위입니다.
